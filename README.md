# Scanzo

Scanner le code-barres d'un produit et comparer son prix chez Migros, Coop, Denner, Lidl et Aldi.

Projet personnel d'apprentissage. Données produits : [Open Food Facts](https://world.openfoodfacts.org) (licence ODbL).

## Statut
En ligne sur https://lucasheimcorrea-sys.github.io/scanzo/ : scan, fiche produit, prix par filiale (canton de Neuchâtel) et comparaison entre enseignes. Projet en cours.
